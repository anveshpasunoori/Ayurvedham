# Photo expansion
The atlas exposes existing credited images and species-specific Commons search links for every plant entry (mineral pitch excluded from botanical search). External search results are not curated or endorsed. The candidate collector queries Commons for up to 15 files per species, filters MIME and licence metadata and writes an unpublished review queue. Metadata alone does not prove botanical identity or that a file is a photograph. Review every candidate, preserve attribution and licence, verify image URLs and avoid patient photos without appropriate consent. Do not render raw metadata HTML. No new image files or verified image records were added in this round because network access to Commons was unavailable in the execution environment.
