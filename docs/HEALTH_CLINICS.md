# Health and clinics
Health is a link-based educational portal, not a licensed WebMD integration. No third-party articles copied. Topic URLs require link validation. Clinics reads the existing verified-only API when deployed; static hosting shows a disconnected state. Appointment policy and proposed SQL are foundations only, not a working booking service. No health data collection, diagnosis, video calls or payments. Next: credential review, authentication, transactional availability and appointments, patient consent, privacy review, localization, clinical editorial review and browser testing.
