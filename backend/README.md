# Backend integration boundaries
The SQL schema and pure policy modules are not a running backend. Use a managed OIDC identity provider and PostgreSQL with a least-privilege application role. Verify issuer, audience, expiry and signature on every authenticated request. Resolve account IDs from trusted subject mapping; never accept roles from browser requests. Check ownership and institution membership on every query. Do not grant public database access.
Razorpay signature verification helper is provided; no webhook endpoint or checkout is active. Use raw request bytes, a secret supplied through environment configuration, and a transaction with unique provider/event ID to prevent duplicate processing. Reconcile subscriptions with provider API and validate plan, currency and amount before granting entitlements. Never grant access from client success callbacks.
